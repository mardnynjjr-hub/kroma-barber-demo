# KROMA Barber Co. — Demo Page

A single-page concept site for a fictional appointment-only barbershop in Sihanoukville, Cambodia. Built as a design demo — not a real business.

## What's here

- [`kroma-barber-demo.html`](kroma-barber-demo.html) — a self-contained, single-file page (HTML, CSS, and a small amount of vanilla JS, no build step or dependencies).

## Viewing it

Open `kroma-barber-demo.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/kroma-barber-demo.html`.

## Sections

- Hero and shop stats
- About
- Services & pricing
- Barber profiles
- Gallery (before/after)
- Booking form (Netlify Forms markup)
- Location / visit info

All copy, prices, contact details, and photos are placeholders for demo purposes.
